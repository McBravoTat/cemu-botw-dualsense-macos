# Changelog

## 0.1.0 — initial experimental public source

* Shared Bluetooth DualSense R2 output and standalone diagnostic modes.
* Read-only, version-checked EU Wii U BOTW v208 game-state bridge.
* Bow pre-arming, shot release/re-arm, Sword/inventory/map suppression.
* Dependency/build checks, controller/library selection and explicit unverified-build opt-in.
* Source-only distribution, bilingual instructions, software tests and CI.

Only the baseline described in COMPATIBILITY.md was observed live; publication software
checks do not expand the hardware/game compatibility claim.
