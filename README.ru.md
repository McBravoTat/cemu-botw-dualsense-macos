# Адаптивный R2 DualSense для Cemu BOTW на macOS

[English](README.md) · [Совместимость](COMPATIBILITY.md) · [Устройство телеметрии](TELEMETRY.md)

Экспериментальный мост читает состояние **Wii U BOTW** и готовит профиль лука, пока лук
в руках. При выстреле профиль снимается и готовится снова; меч, инвентарь и карта
выключают его в проверенной версии. Обычный ввод остаётся у Cemu.
Первое доставание убранного лука ещё может запаздывать.

## Установка

Нужны Apple Silicon, обычный DualSense по Bluetooth, arm64 Python 3.10+, Homebrew hidapi
0.12+ и Command Line Tools. Проверена европейская Wii U BOTW v208 и конкретный бинарник
Cemu 3005cb7. Точные хеши и ограничения указаны в COMPATIBILITY.md.
Другие сборки и версии автоматически не объявляются рабочими.

Скачайте **Code -> Download ZIP** и распакуйте проект либо выполните:

```bash
git clone https://github.com/McBravoTat/cemu-botw-dualsense-macos.git
cd cemu-botw-dualsense-macos
brew install python hidapi
chmod +x "Start BOTW Triggers.command"
python3 doctor.py
```

Если нет Command Line Tools: `xcode-select --install`.
Закройте обычный Cemu и дважды нажмите **Start BOTW Triggers.command**, либо запустите:

```bash
python3 launch_botw.py
```

Продолжите игру и достаньте лук. В Cemu ZR должен быть назначен на физический R2.
По умолчанию используются ваши **обычные данные и сохранения Cemu**. Для эксперимента
с отдельной копией: `python3 launch_botw.py --mlc /путь/к/копии/mlc01`.
Мост не редактирует сохранения/настройки; сама игра может сохранять обычный прогресс.

Проверка зависимостей ничего не запускает: `python3 launch_botw.py --check`.
Другой путь к приложению задаётся через `--cemu /путь/к/Cemu.app`.
Для явно экспериментальной проверки неизвестной сборки есть `--experimental-cemu --dry-run`:
это не подтверждение совместимости, проверки игровых данных остаются включены.

## Работа

Профиль остаётся подготовленным между нажатиями, пока лук в руках. Это нужно для
последующих быстрых нажатий. При сне DualSense нажмите PS — мост ждёт переподключения.
При закрытии Cemu или Ctrl+C выполняется попытка off. После остановки можно отдельно
выполнить `python3 bridge.py off`.
После обрыва Bluetooth, SIGKILL или выключения питания доставка off не гарантирована.
Не запускайте второй мост или другой отправитель эффектов одновременно.

Обычный запуск Cemu напрямую не включает этот модуль: используйте подготовленный launcher.
Локально собранный модуль лежит в .runtime/, журналы — в logs/; эти папки не публикуются.
Не прикладывайте к issues адрес контроллера, личные пути, сохранения и дампы памяти.

Это ранний прототип. Не проверены все руны, луки, отсутствие стрел, все кат-сцены,
переходы загрузки и длительная игра. Фокус другого приложения пока не является отдельным
сигналом выключения. Текущий журнал живой проверки сообщал macOS 27.2.1; отдельная
проверка игрового режима на первоначально указанной 26.2 не заявляется.

```bash
python3 -m unittest discover -s tests -v
```
